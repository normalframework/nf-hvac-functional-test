Arm scheduled live runs

When armed, the next due occurrence starts a live functional test with no one at the console. It overrides dampers, valves and, if enabled, VAV boxes through the NF command service.

  • Every write is a named NF command with an expiry. It reverts on its own if the app stops.
  • The run releases every override on completion, abort, interlock, timeout and error.
  • The site configuration must also allow live writes (dry_run: false), or the run stays a rehearsal.
  • Changing the schedule, windows or blackout disarms it.
Dry-run is the default. Overrides use the NF command service at the configured BACnet priority.
